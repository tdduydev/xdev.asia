# Current-style xDev logo family

The user chose to retain the existing website logo style. These assets extend the current native SVG originals; generated concept boards v1–v4 are not the selected direction.

- Keep the blue X, DEV lettering, and original color treatments.
- Product lockup: add AI STUDIO below DEV without changing the master mark.
- Light and dark versions match the backgrounds they are named for.
- The monochrome version uses currentColor when inlined.
- App icons share the X; the AI Studio variant adds a short underline.
- SVGs retain live text, as in the original assets. For brand-accurate external exports, convert text to outlines with the selected typeface; do not assume an arbitrary system has the same font.
